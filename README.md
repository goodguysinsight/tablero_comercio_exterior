# Observatorio de Comercio Exterior del Perú

Tablero interactivo con las variables del *Reporte Mensual de Comercio* de MINCETUR (agosto 2026): panorama, exportaciones, socios y mercados, regiones, importaciones, sectores, empresas y transporte.

- `index.html`: tablero autónomo (datos y mapas incluidos). Es el único archivo necesario para GitHub Pages.
- `datos/`: datos estructurados usados en el tablero (referencia).
- `.nojekyll`: evita el procesamiento de Jekyll en GitHub Pages.

Fuente: SUNAT, Banco Mundial; MINCETUR-VMCE-DGIECE-DDPI.
Elaboración: **Good Guys Insight**.
